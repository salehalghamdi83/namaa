# نماء — دليل التشغيل

موقع مستقل لمتابعة الأبناء، يعمل من المتصفح ويُثبَّت على الشاشة كتطبيق، بلا بريد إلكتروني ولا برامج.

## مكونات المشروع
| الملف | ما هو |
|---|---|
| `index.html` | التطبيق كاملًا (يُبنى من مجلد `src` بالأمر `./build.sh`) |
| `config.js` | **الملف الوحيد الذي تعدّله**: عنوان Supabase والمفتاح العام ومفتاح الإشعارات |
| `sw.js`، `manifest.webmanifest`، `icon-*.png` | التثبيت على الشاشة، والعمل بدون إنترنت، والإشعارات |
| `vendor/supabase.js` | مكتبة الاتصال بقاعدة البيانات (محفوظة محليًا) |
| `supabase/schema.sql` | قاعدة البيانات والصلاحيات (تُشغَّل مرة واحدة) |
| `supabase/functions/ai` | دالة الذكاء الاصطناعي (المرشد والشرح والتحليل) |
| `supabase/functions/notify` | دالة إشعارات الجوال |
| `tools/vapid.html` | أداة توليد مفاتيح الإشعارات |

## خطوات التشغيل (مرة واحدة)

### 1) قاعدة البيانات — Supabase
1. أنشئ حسابًا في supabase.com (يمكن الدخول بحساب GitHub)، ثم **New project**. اختر اسم `namaa` وأقرب منطقة متاحة، واحفظ كلمة مرور قاعدة البيانات عندك.
2. **SQL Editor ← New query**: الصق محتوى `supabase/schema.sql` كاملًا ثم **Run**.
3. **Authentication ← Sign In / Providers**: فعّل **Allow anonymous sign-ins** (هذا ما يتيح الدخول بلا بريد).
4. **Project Settings ← API**: انسخ **Project URL** والمفتاح العام (**anon** أو **publishable**) وضعهما في `config.js`.

### 2) مفاتيح الإشعارات
افتح `tools/vapid.html` في المتصفح واضغط «توليد المفاتيح»:
- المفتاح العام ← في `config.js` (خانة `vapidPublic`) وفي أسرار Supabase باسم `VAPID_PUBLIC`.
- المفتاح الخاص ← في أسرار Supabase فقط باسم `VAPID_PRIVATE`.

### 3) الذكاء الاصطناعي — Claude API
1. في console.anthropic.com أنشئ مفتاح API، واشحن رصيدًا صغيرًا، وضع **حدًا شهريًا للإنفاق**.
2. في Supabase: **Edge Functions ← Secrets** أضف `ANTHROPIC_API_KEY`.
3. اختياري: `AI_DAILY_LIMIT` (الافتراضي 300 طلب يوميًا للعائلة).

### 4) الدوال
في Supabase: **Edge Functions ← Deploy a new function ← Via Editor**:
- دالة باسم `ai` والصق محتوى `supabase/functions/ai/index.ts`.
- دالة باسم `notify` والصق محتوى `supabase/functions/notify/index.ts`.

### 5) النشر — GitHub Pages
1. ارفع كل الملفات (عدا مجلد `test`) إلى مستودع اسمه `namaa`.
2. **Settings ← Pages ← Deploy from a branch ← main / root**.
3. يصبح الموقع: `https://اسم-حسابك.github.io/namaa/`

## أول استخدام
1. **الأب**: افتح الموقع ← «إنشاء عائلة» ← اختر «انقل عائلتك من نماء السابق» والصق البيانات المصدّرة، أو أنشئ عائلة جديدة.
2. احفظ **رمز العائلة** الذي يظهر (مثل `NAMAA-123456`).
3. **على جهاز كل فرد**: افتح الموقع في Chrome ← ⋮ ← «إضافة إلى الشاشة الرئيسية» ← افتحه ← أدخل رمز العائلة ← اختر الاسم ← الرمز السري. يبقى الجهاز مسجّلًا بعدها.
4. **جوال الأب والأم**: اضغط «تفعيل الإشعارات» في اللوحة.
5. **الآيفون**: من Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية» أولًا، ثم افتحه من الأيقونة وفعّل الإشعارات.

## الأمان
- الرموز السرية وكلمات المرور تُحفظ مشفّرة (bcrypt)، وتُقفل المحاولات بعد 8 أخطاء لمدة 15 دقيقة.
- كل عائلة لا ترى إلا بياناتها، ولا يغيّر الإعدادات والمكافآت إلا الأب (مطبّق في قاعدة البيانات نفسها).
- مفتاح Claude ومفتاح الإشعارات الخاص على الخادم فقط، ولا يصلان لأي جهاز.
- التسجيلات الصوتية خاصة بالعائلة، وتُحذف تلقائيًا بعد تقييمها.
- من «العائلة ← الأجهزة المسجّلة» ترى كل جهاز وتسحب دخوله.

## التعديل لاحقًا
عدّل ملفات `src/` ثم شغّل `./build.sh` لإعادة بناء `index.html`، وارفع التغييرات إلى GitHub.
